One-line commit message for a bug fix that made everything worse.

## Entry

```
fix: prevent lost drafts by publishing on every keystroke
```

57 characters. A "fix" for lost drafts that publishes on every keystroke —
the repair itself becomes the disaster: every half-typed thought goes live.

## How it works

`main.ts` writes the entry text to `/output/entry.txt` (creating `/output`
first). Run with Node 22.18+:

```
node main.ts
```
